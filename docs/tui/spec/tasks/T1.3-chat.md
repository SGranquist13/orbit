# T1.3 Chat screen

**Goal.** A whole conversation from the terminal: open a workspace, read the live transcript, type, send, stop.

**Depends on:** T1.2.

**Files you may touch:**
- `crates/orbit-tui/src/{view/chat.rs,view/header.rs,view/input.rs,store.rs,history.rs}`, `src/app.rs`, `src/msg.rs`, `src/cmd.rs`, `src/main.rs`

**Spec:** [visual.md](../visual.md) §3.1, §3.3, §3.4, [keys.md](../keys.md) §2, Chat — Input, Chat — Transcript, [behaviour.md](../behaviour.md) §1.2, §1.5, §6, §7 (`orbit <ws>`; start screen = most recent workspace until T2.3)

## Steps
1. `store.rs`: snapshot state (repos, workspaces, summaries), per-workspace events (LRU 4), apply pushes, gap fetch, reconnect refetch.
2. Header, input (`tui-textarea`, history, placeholder, grows 1–8), footer hints, focus model, Esc interrupt, Ctrl+Y (OSC 52), Ctrl+E external editor.
3. `markSeen` when a workspace is opened and when new events arrive while it's on screen.
4. Disconnect/reconnect UI.

## Tests
- `update` tests: send flow (pending block, error restores input), Esc semantics by focus, history navigation, push application including gaps.
- Snapshots: idle, running, disconnected, long input, unpinned scroll with new content.

- [ ] `cargo test -p orbit-tui` passes

- [ ] Maintainer: hold a conversation with a Claude and a Codex workspace; desktop mirrors it; stop works; app restart reconnects
