# T3.2 Ship overlay

**Goal.** Ship from the terminal with live progress and merge.

**Depends on:** T3.1.

**Files you may touch:**
- `crates/orbit-tui/src/{ship.rs,view/ship.rs}`, `src/app.rs`, `src/store.rs` (polling)

**Spec:** [behaviour.md](../behaviour.md) §5, [visual.md](../visual.md) §3.7 Ship, [keys.md](../keys.md) Ship overlay
