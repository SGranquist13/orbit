# T2.2 Inbox screen

**Goal.** The full-screen Inbox with one-key actions, and notifications for workspaces that start needing you.

**Depends on:** T2.1, T3.0.

**Files you may touch:**
- `crates/orbit-tui/src/{view/inbox.rs,notify.rs}`, `src/app.rs`, `src/view/confirm.rs`

**Spec:** [visual.md](../visual.md) §3.6, [keys.md](../keys.md) Inbox, [behaviour.md](../behaviour.md) §2.3–§2.5

## Steps
1. Inbox view and keys, rule suggestions 1–3, archive with force confirm, dismiss.
2. `notify.rs` bell + OSC 9 with the 30 s rate limit and `--quiet`.
3. Alt+2 / Ctrl+X 2 / Esc back to the previous screen.

## Tests
- `update` tests for each action → expected `Cmd`.
- Notification rate limit test.
- Snapshots: mixed inbox at both sizes, empty inbox ("Nothing needs you." centred `mute`).
