# T3.1 Skills popup, @ files, palette, profile cycle, pinned chips

**Goal.** Everything that makes the input powerful.

**Depends on:** T1.3, T3.0.

**Files you may touch:**
- `crates/orbit-tui/src/{view/popup.rs,view/palette.rs,fuzzy.rs,commands.rs,view/help.rs}`, `src/view/input.rs`, `src/app.rs`, `src/settings.rs`

**Spec:** [keys.md](../keys.md) Popups, Chat — Input (`/`, `@`, Ctrl+O), §4 Ctrl+X, §5 Palette, F1 help, [visual.md](../visual.md) §3.3 chips, §3.7, [protocol.md](../protocol.md) `listSkills`, `runSkill`, `listFiles`, `listProfiles`, `switchProfile`

## Steps
1. `fuzzy.rs` subsequence matcher with the ranking in keys.md.
2. Skills popup (list cached per workspace, refreshed on open), Enter runs `runSkill` with typed args.
3. `@` file picker (`listFiles` cached per workspace for 60 s).
4. `commands.rs`: the command registry the palette, help overlay and Ctrl+X chord share.
5. Pinned chips from `tui.json`; Ctrl+O profile cycle.

## Tests
- Fuzzy ranking tests.
- Popup open/close/complete `update` tests.
- Snapshots: skills popup filtered, file popup, palette, help overlay.
