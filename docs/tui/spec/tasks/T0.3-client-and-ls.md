# T0.3 Client, `orbit ls`, `orbit send`

**Goal.** Ship the first usable binary: a client library and two plain-text commands.

**Depends on:** T0.1 (T0.2 merged for the live check).

**Files you may touch:**
- `crates/orbit-proto/src/client.rs` (+ `client` feature: `tokio`, `tokio-tungstenite`, `futures-util`, `dirs`)
- `crates/orbit-tui/**` (new crate, bin `orbit`): `main.rs`, `cli.rs`, `cmd_ls.rs`, `cmd_send.rs`

**Spec:** [protocol.md](../protocol.md) §5, [behaviour.md](../behaviour.md) §2.2 (grouping, without PR status), §6, §7

## Steps
1. `read_local_config`, `Client::connect_local`, `rpc`, push channel, reconnect as specified.
2. CLI with `clap` (derive): subcommands `ls [--json]`, `send <ws> <text>`, and the TUI flags parsed but unused for now (no subcommand → print "TUI coming in T1" and exit 0).
3. `ls`: `snapshot`, group with a temporary rule (running / errored-unseen / other) until T2.1 ports attention; print the columns from behaviour.md §7; `--json` as specified.
4. Workspace lookup helper (exact name, else unique prefix of name or id; ambiguous → error listing matches) in `crates/orbit-tui/src/lookup.rs`, reused later.
5. Errors per behaviour.md §6 (`Orbit isn't running…`, exit 1).

## Tests
- Client against an in-process fake server (a small tokio WebSocket server in the test that speaks the local handshake): connect, rpc ok/err, push delivery, reconnect after the server restarts on a new port with a new `local.json` (use a temp `ORBIT_HOME`).
- `lookup` unit tests.
- `ls` output snapshot from a fixture snapshot JSON.

- [ ] With the app running: `orbit ls` lists workspaces; `orbit send <ws> "say pong"` makes the desktop transcript show the message (maintainer)
