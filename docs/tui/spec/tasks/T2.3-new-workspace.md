# T2.3 New workspace dialog and start screen

**Goal.** Create workspaces from the TUI and land on the right screen at startup.

**Depends on:** T2.1, T3.0.

**Files you may touch:**
- `crates/orbit-tui/src/view/new_workspace.rs`, `src/app.rs`, `src/main.rs`

**Spec:** [behaviour.md](../behaviour.md) §3, §7 (start screen), [visual.md](../visual.md) §3.7 (New workspace), [keys.md](../keys.md) Global Ctrl+N, Rail `n`

## Steps
1. Dialog with pickers fed by `snapshot.repos`, `hello.agents`, `listProfiles`.
2. `createWorkspace` with `task`; open the new workspace.
3. Start screen rule.

## Tests
- Field navigation and validation tests.
- Snapshots of the dialog at both sizes.

## Done when
- [ ] `cargo test -p orbit-tui` passes
- [ ] `cargo clippy -p orbit-tui -- -D warnings` and `cargo fmt --check` clean
- [ ] Maintainer: a workspace created from the TUI starts its agent and appears on the desktop
