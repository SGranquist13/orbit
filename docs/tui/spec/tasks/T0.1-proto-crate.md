# T0.1 Cargo workspace + orbit-proto types

**Goal.** Turn the repo into a Cargo workspace and create `crates/orbit-proto` with the wire types, so the app and the TUI share one definition.

**Depends on:** nothing.

**Files you may touch:**
- `Cargo.toml` (new, repo root: `[workspace] members = ["src-tauri", "crates/*"]`, `resolver = "2"`, shared `[workspace.package]` edition 2021)
- `crates/orbit-proto/**` (new)
- `src-tauri/Cargo.toml` (only if the workspace move requires it, e.g. moving `[profile.*]` to the root)
- `.gitignore` (root `target/`)
- `scripts/cargo.cmd` (only if its `--manifest-path` must change; keep `bun run` scripts working)

**Spec:** [protocol.md](../protocol.md) §2–§4

## Steps
1. Create the workspace. Check `cargo metadata` from the root lists `src-tauri`. Keep `Cargo.lock` at the root (move it; don't regenerate versions: `git mv src-tauri/Cargo.lock Cargo.lock`, then `cargo metadata` must not change any version).
2. `orbit-proto` modules: `frames` (Hello, Local, Ready, Error, Rpc, RpcResult, pushes as one `#[serde(tag = "t")]` enum `ServerFrame` and `ClientFrame`), `types` (Workspace, Summary, Repo, StoredEvent, AgentEvent and its nested types, Skill, Profile, PrStatus/Checks, PrepareShip/CheckResult, MergeOutcome, FileChange, Review, Scope, ReviewComment, Hello settings), `methods` (one const per method name + typed `Params`/`Result` pairs).
3. Copy field lists exactly from the cited Rust files in `src-tauri` (all `camelCase`). Every struct gets `#[serde(default)]` on optional/new fields; `AgentEvent` gets a final `#[serde(other)] Unknown` variant.
4. Dependencies: `serde`, `serde_json` only (the client in T0.3 adds tokio etc. behind a `client` feature).

## Tests
- Round-trip each frame type through JSON with a hand-written sample from protocol.md.
- Deserialize every line of every `src-tauri/tests/fixtures/*.jsonl` that is an Orbit `AgentEvent` (skip raw agent lines that fail the `type` tag: count them, assert > 0 parsed).

## Done when
- [ ] `cargo test -p orbit-proto` passes
- [ ] `cargo clippy -p orbit-proto -- -D warnings` and `cargo fmt --check` clean
- [ ] `cargo metadata` shows no version changes vs `main`
- [ ] `bun run` scripts that call `scripts/cargo.cmd` still work (maintainer checks on Windows)

## Notes
The app's package is `orbit` (lib `orbit_lib`); new crates must not use the bin name `orbit` (see behaviour.md B3).

Do **not** make `src-tauri` depend on `orbit-proto` yet (that's T0.2, which needs the Windows toolchain).
