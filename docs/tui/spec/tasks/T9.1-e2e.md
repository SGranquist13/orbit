# T9.1 e2e steps

**Goal.** Real-app e2e coverage per milestone, kept cheap (haiku, one-line prompts).

**Depends on:** the milestone's tasks.

**Files you may touch:**
- `scripts/e2e.mjs`, `scripts/e2e-harness.mjs` (a PTY helper using `node-pty` or the app's own PTY via CDP)

**Spec:** CLAUDE.md e2e rules, [keys.md](../keys.md) §1 (answer `ESC[6n` with `ESC[1;1R`)

## Steps
1. `tui-ls` (T0): `orbit ls --json` lists the e2e workspace.
2. `tui-chat` (T1): run `orbit <ws>` in a PTY, type a one-line haiku prompt, wait for the reply text on screen and in the desktop transcript.
3. `tui-inbox` (T2): a finished workspace shows under needs you; Enter opens it.
4. `tui-review` (T4): comment on a line, send, the desktop transcript shows the review message.
5. `tui-pane` (T5): open the pane from the palette and see the TUI header.

## Tests
- Each step passes alone (`node scripts/e2e.mjs tui-chat`) after the prerequisites.
