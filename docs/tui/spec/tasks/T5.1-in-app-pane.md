# T5.1 In-app Terminal UI pane + installer [app]

**Goal.** Run the TUI inside the desktop app and ship the binary with the installer.

**Depends on:** T3.2.

**Files you may touch:**
- `src/components/` (new `TerminalUi.tsx`), `src/stores/app.ts` (view), nav + `Palette.tsx` entry, `src/lib/keybindings.ts`
- `src-tauri/src/code/pty.rs` (spawn with env), `src-tauri/tauri.conf.json` (`bundle.externalBin` or resources for `orbit.exe`)
- `package.json` build script to build `orbit-tui` in release before `tauri build`

**Spec:** [../../tui.md](../../tui.md) T5, [protocol.md](../protocol.md) §1 (env override), [visual.md](../visual.md) §1 (`--paint-bg`)

## Steps
1. Nav item and palette entry "Terminal UI"; full-pane xterm.js reusing the Code view's terminal component; spawns the bundled `orbit --paint-bg --theme <desktop theme>` with `ORBIT_LOCAL_TOKEN`/`ORBIT_LOCAL_PORT`.
2. Installer: include `orbit.exe`; optional PATH entry (NSIS checkbox, default off).
3. Check `orbit` for clashes on PATH (behaviour.md B3) and report.

## Tests
- e2e step `tui-pane` (T9.1).

## Done when
- [ ] `bunx tsc --noEmit`, `bun run build`, `scripts/cargo.cmd test` pass
- [ ] Installer builds and the pane works from an installed build (maintainer)
