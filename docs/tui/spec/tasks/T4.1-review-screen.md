# T4.1 Review screen

**Goal.** Full-screen diff review with scopes and comments sent to the agent.

**Depends on:** T4.0, T2.1.

**Files you may touch:**
- `crates/orbit-tui/src/{review.rs,diff.rs,view/review.rs}`, `src/app.rs`

**Spec:** [behaviour.md](../behaviour.md) §4, [visual.md](../visual.md) §3.8, [keys.md](../keys.md) Review

## Steps
1. `diff.rs`: `similar` line diff → hunks with context and merging rule; old/new line numbers.
2. `review.rs` (pure): files, accepted set, cursor, ranges, drafts, scope cycling.
3. View + keys; send with confirm.

## Tests
- Diff hunking tests (adjacent hunks merge at ≤ 6, context 3, add-only/delete-only files).
- Comment excerpt/side tests.
- Snapshots: file list + diff at both sizes, comment being typed, commit scope (read-only), binary/large file.

## Done when
- [ ] `cargo test -p orbit-tui` passes
- [ ] `cargo clippy -p orbit-tui -- -D warnings` and `cargo fmt --check` clean
- [ ] Maintainer: comment on two lines, send, the agent receives one message in the same format as the desktop's
