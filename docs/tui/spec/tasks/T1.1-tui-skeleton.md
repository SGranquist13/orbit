# T1.1 App loop, theme, glyphs, snapshot harness

**Goal.** The TUI's skeleton: terminal setup/teardown, the Elm loop, theme + colour depth, glyphs, layout frame, and the snapshot-test harness every later task uses.

**Depends on:** T0.3.

**Files you may touch:**
- `crates/orbit-tui/src/{tui.rs,app.rs,msg.rs,cmd.rs,theme.rs,glyphs.rs,layout.rs,view/mod.rs,view/footer.rs,settings.rs}`
- `crates/orbit-tui/tests/snap.rs`, `crates/orbit-tui/tests/fixtures/**`

**Spec:** [visual.md](../visual.md) §1, §2, §3 (frame, footer, minimum size), §4, §6, [keys.md](../keys.md) §1, Global table (only Ctrl+C, Ctrl+L, Ctrl+B), §6, [../README.md](../README.md) rule 3

## Steps
1. `tui.rs`: raw mode, alt screen, bracketed paste, mouse (scroll), kitty flags when supported, panic hook + signal restore.
2. `app.rs`: `App` model; `update(&mut App, Msg) -> Vec<Cmd>`; `Msg` = Key, Paste, Mouse, Resize, Tick(now_ms), Push(Push), RpcDone(id, Result). Runtime: one tokio task reading crossterm `EventStream`, the client push channel and a tick interval (only while `app.animating()`), feeding `update`, executing `Cmd`s, redrawing when `app.dirty`.
3. `theme.rs`: tokens table, Void/Paper, colour depth detection and `--color`, `NO_COLOR`, OSC 11 auto-detect with timeout.
4. `glyphs.rs`: Unicode/ASCII sets.
5. `layout.rs`: computes rail/main/header/transcript/input/footer rects from W×H, `railSide`, rail visibility; min-size screen.
6. `settings.rs`: `~/.orbit/tui.json` read/write preserving unknown keys.
7. A placeholder main pane ("No workspace open" centred, `mute`) so the binary runs end to end.

## Tests
- `layout` unit tests for 59×16, 60×16, 80×24, 99×30, 100×30, 140×40 × rail left/right/off.
- Theme: depth detection from env tables; 16-colour mapping.
- Snapshot harness: render `App` into `TestBackend` and serialise cells + a compact style legend; first snapshots of the placeholder at the §6 matrix sizes.
