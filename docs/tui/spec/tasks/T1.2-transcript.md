# T1.2 Transcript fold, markdown, block rendering

**Goal.** Port the transcript folding and render every block kind as visual.md specifies.

**Depends on:** T1.1.

**Files you may touch:**
- `crates/orbit-tui/src/transcript.rs`, `src/format.rs` (formatTokens etc.), `src/markdown.rs`, `src/view/transcript.rs`
- `crates/orbit-tui/tests/gen-goldens.ts`, `tests/goldens/**`, `tests/fixtures/**`

**Spec:** [behaviour.md](../behaviour.md) §1, [visual.md](../visual.md) §3.2, §4, §5

## Steps
1. Port `fold`, `toolSummary`, `formatTokens`, `formatCost`, `formatDuration`, `turnUsageTokens` from `src/lib/transcript.ts`.
2. `gen-goldens.ts` (run with `bun`): imports the TS `fold` and writes `tests/goldens/<fixture>.json` for each fixture. Commit the goldens.
3. Incremental refold (§1.2), live text, edit counts (§1.3), fold/expand state (§1.4).
4. `markdown.rs`: pulldown-cmark → `Vec<Line>` at a given width with the visual.md §5 mapping.
5. `view/transcript.rs`: blocks → lines with scroll offset and stick-to-bottom; `↓ new` marker.

## Tests
- Fold goldens match for every fixture.
- Markdown unit tests: each construct at width 40 and 100.
- Snapshots: one scenario per block kind; a long mixed transcript at both sizes; running turn with live text and sweep frame 0 and 1.

## Done when
- [ ] `cargo test -p orbit-tui` passes
- [ ] `cargo clippy -p orbit-tui -- -D warnings` and `cargo fmt --check` clean
- [ ] Goldens regenerate byte-identical with `bun crates/orbit-tui/tests/gen-goldens.ts`
