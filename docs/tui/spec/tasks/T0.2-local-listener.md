# T0.2 Local listener, async backend, new pushes [app]

**Goal.** Add the always-on loopback listener with token auth and plaintext frames, make `Backend::rpc` async, and publish the two new pushes.

**Depends on:** T0.1.

**Files you may touch:**
- `src-tauri/Cargo.toml` (add `orbit-proto` path dependency)
- `src-tauri/src/remote/server.rs`
- `src-tauri/src/remote/mod.rs`
- `src-tauri/src/lib.rs` (setup: start the local listener; publish `workspace-removed` and `summary` where the desktop is told)
- `src-tauri/src/routines.rs`, `src-tauri/src/attempts.rs` (only the lines that emit `workspace-archived`, to also publish)
- `ide_mobile/docs/protocol.md` if the repo is available; otherwise put the section text in the PR description for the maintainer

**Spec:** [protocol.md](../protocol.md) §1, §2, §3 ("Existing" only), §4

## Steps
1. `Backend::rpc` → async (boxed future). Move the `spawn_blocking` from `run_rpc` into `OrbitBackend`; the five existing methods keep exact behaviour.
2. `ServerConfig` gets `mode: Phone | Local { token }`. `handle_connection` uses a `Transport` enum (Sealed/Plain). Local mode accepts `t: "local"` with a constant-time token check; replies `ready` in plaintext; plain frames after.
3. `remote::start_local(app, state)` called from `run()` setup: binds `127.0.0.1:0`, writes `local.json` atomically (protocol.md §1), deletes it on exit (`RunEvent::Exit`).
4. Publish `{t:"workspace-removed"}` next to every `workspace-archived` emit, and `{t:"summary"}` after an event is persisted in `on_agent_event` (bind the summary first; do not call `db()` inside an expression that already holds it).
5. Bump `PROTOCOL_VERSION` to 2. Phone handshake is otherwise unchanged.
6. Add a test that serialises `Workspace`, `Summary`, `StoredEvent`, `AgentEvent` (all variants), `PrStatus`, `PrepareShip` from `src-tauri` and deserialises them with `orbit-proto` (keeps T0.1's copies honest).

## Tests
- Existing `server.rs` tests still pass (phone pair/auth/rpc/revoke).
- New: local handshake ok; bad token → `bad_token`; `local` on phone listener → `protocol`; rpc over plain frames; pushes reach a local client; `local.json` contents and permissions (Unix).
